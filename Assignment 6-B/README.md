# Assignment 2: Name and City Form Using Two Pages

## Run
1. Extract this ZIP and open the extracted folder in VS Code.
2. Open Terminal and run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Features
- Page 1 accepts Name and City.
- Submit navigates to Page 2.
- Page 2 displays the submitted Name and City.
- Uses `react-router-dom` for navigation.
